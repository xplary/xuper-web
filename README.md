# Xuper Web

Explora películas, series y canales en vivo desde el navegador de tu celular o computadora.

**[Entrar a Xuper Web](https://xuper-web.onrender.com/)**

## Cómo usar la web

1. Abre el enlace y espera a que aparezca el catálogo.
2. Busca una película o serie por su nombre, o explora las secciones **Top 10 películas**, **Top 10 series** y **Recién agregados**.
3. Abre la ficha del título. Para ver una película, pulsa **Reproducir**. Para ver una serie, baja a **Episodios**, elige la temporada y pulsa el capítulo que quieras ver.

Para ver un canal, abre **TV en vivo** y selecciona su nombre. Para retomar una película o serie que ya empezaste, abre **Historial** y elige el título.
